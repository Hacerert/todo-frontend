# Todo App Frontend

Angular ile geliştirilmiş Todo uygulaması arayüzü.

## Teknolojiler

- Angular
- TypeScript
- HTML
- CSS
- Docker

## Özellikler

- Kullanıcı girişi
- Todo ekleme
- Todo listeleme
- Görev tamamlama
- Görev silme

## Çalıştırma

### Geliştirme ortamı

```bash
npm install
npm start
```

### Docker

```bash
docker build -t todo-frontend .
docker run -p 4200:4200 todo-frontend
```
